## このガイドの位置付け

オリジナルケースは、標準ケースや簡易ケースキットを使わず、自分でケース構造を設計・製作する選択肢です。
配布されているSTEPファイルはPCB外形の参照用であり、ケースとしてそのまま使えるデータではありません。

> [!IMPORTANT]
> オリジナルケースの設計・製作は自己責任で行ってください。
> PCB、LiPoバッテリー、USBポート、電源スイッチ、キースイッチ、ネジなどに無理な力がかからないように設計し、組み込み後に安全性を確認してください。

## 参照できるデータ

左右PCBの外形データとして、以下のSTEPファイルを参照できます。これらはKiCadから出力したmm単位のデータです。

| 対象 | ファイル |
|---|---|
| 左PCB | [left.step](../models/pcb/left.step) |
| 右PCB | [right.step](../models/pcb/right.step) |

標準ケースの構造を参考にしたい場合は、[ケースの3Dモデル](../models)も確認できます。

## 設計前に決めること

ケースを設計する前に、以下を決めておくと必要な寸法や固定方法を整理しやすくなります。

| 決めること | 確認する内容 |
|---|---|
| 使用するキースイッチ | MX互換、ChocV1/V2互換、または両対応にするかを決めます。 |
| トッププレート構造 | スイッチをどの部品で保持し、PCBへどのように固定するかを決めます。 |
| バッテリー位置 | 使用するLiPoバッテリーのサイズ、固定方法、ケーブルの逃げを決めます。 |
| 電源スイッチの操作方法 | 基板上の電源スイッチに指やノブが無理なく届く構造を決めます。 |
| USBポートへのアクセス | ファームウェア書き込み、充電、ZMK Studio使用時にUSB Type-Cケーブルを接続できる形状にします。 |
| ケース固定方法 | ネジ、スペーサー、インサートナットなど、PCBやトッププレートに無理がかからない固定方法を決めます。 |

## 設計時のチェックポイント

設計中は、少なくとも以下を確認してください。

- PCB外形、部品実装面、XIAO nRF52840 Plus、バッテリーコネクタ、ホットスワップソケットがケースと干渉しない
- キースイッチのピンが曲がらず、ホットスワップソケットへまっすぐ入る
- キースイッチ、キーキャップ、トッププレート、ケースが互いに干渉しない
- 電源スイッチをON/OFFでき、スイッチ本体に横方向の過剰な力がかからない
- USB Type-Cケーブルを無理なく抜き差しできる
- LiPoバッテリーが圧迫、穴あき、強い曲げ、ショートの危険がない状態で固定できる
- バッテリーケーブルがネジ、トップカバー、PCBなどに挟まれない
- 金属部品を使う場合、PCBの露出パッドやバッテリー端子と短絡しない

> [!CAUTION]
> LiPoバッテリーはショートや強い曲げ、穴あき、圧迫で発熱・発火する可能性があります。
> ケース設計時は、バッテリー本体とケーブルに力がかからず、導電部へ触れない固定方法を必ず確保してください。

## 製作後の組み込み確認

製作したケースに基板を組み込む前に、まずケース単体でネジ穴、スイッチ穴、USBポート周辺、電源スイッチ周辺に加工不良や干渉がないか確認します。

基板、キースイッチ、バッテリーを組み込んだら、以下を確認します。

- [ ] 左右の基板がケース内で動かないように固定されている
- [ ] スイッチのピンが曲がらず、ソケットに入っている
- [ ] バッテリーコネクタが奥まで差し込まれている
- [ ] `BAT+`に赤色のケーブル、`GND`に黒色のケーブルが接続されている
- [ ] バッテリーやケーブルがケース、ネジ、PCBに挟まれていない
- [ ] USB Type-Cケーブルを接続できる
- [ ] 電源スイッチを操作できる
- [ ] 左右すべてのキーが入力できる

標準ケースや簡易ケースの組み込み手順を参考にしたい場合は、[標準ケースビルドガイド](03-0-STANDARD_CASE.md)または[簡易ケースビルドガイド](03-1-SIMPLE_CASE.md)も確認してください。
